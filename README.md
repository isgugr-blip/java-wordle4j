# Wordle4j: Русская Консольная Игра в Словечки 🇷🇺🎮

## 📝 О проекте
**Wordle4j** - это русскоязычная реализация популярной игры Wordle, разработанная в качестве домашнего задания для Яндекс Практикума. Попробуйте угадать 5-буквенное русское слово за 5 попыток!

## 🎯 Правила игры
- Угадайте 5-буквенное русское слово
- У вас есть 5 попыток для угадывания слова
- После каждой попытки вы получаете обратную связь:
  - `+` - Буква находится в правильной позиции
  - `^` - Буква существует в слове, но в неправильной позиции
  - `-` - Буквы нет в слове

## ✨ Особенности
- Игра в консольном режиме
- Словарь русских слов
- Автоматическое ведение журнала игровых сессий
- Интеллектуальная система подсказок
- Случайный выбор слова

## 🛠 Требования
- Java 11 или выше
- JUnit 5.4.2 (для тестирования)

## 🚀 Запуск игры
1. Скомпилируйте Java-файлы
2. Запустите класс `Wordle`
3. Начните угадывать русские слова!

### Пример геймплея
```
Введите слово: плита
- ^ - + - -
Осталось попыток: 4
Введите слово: ...
```

## 📂 Структура проекта
- `src/ru/yandex/practicum/`
  - `Wordle.java`: Основная точка входа игры
  - `WordleGame.java`: Основная игровая логика
  - `WordleDictionary.java`: Управление словами
  - `WordleDictionaryLoader.java`: Загрузчик словаря
- `test/`: Тесты JUnit
- `words_ru.txt`: Словарь русских слов

## 🧪 Запуск тестов
Используйте JUnit для запуска набора тестов в `test/ru/yandex/practicum/WordleTest.java`
